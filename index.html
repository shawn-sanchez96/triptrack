About TripTrack

TripTrack is an Android travel tracking application designed to help users organize vacations and their associated excursions. Users can create, view, update, delete, and search stored travel information while keeping trip details organized in one place.

Features

Vacation Tracking

Create and manage vacation details, destinations, hotels, and travel dates.

Excursion Management

Associate activities and excursions with individual vacations.

Trip Search

Search saved vacations by vacation title or hotel.

Travel Reports

Generate vacation and excursion summary reports from stored travel records.

Date Validation

Validate travel dates to help prevent invalid vacation and excursion information.

Local Storage

Travel information is persisted locally using an Android Room database.

Installation

TripTrack is distributed as an Android APK. Download the application using the button above and open the APK on an Android device to begin installation.

  • Android 8.0 (API 26) or newer
  • Installation from downloaded APK files must be permitted on the device
